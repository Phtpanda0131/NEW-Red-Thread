# Red Threads Native Android Home Screen Widget

This directory contains a 100% native Android project built with **Jetpack Glance** (Google's modern declarative framework for Android home screen widgets) featuring **❤️ Heart**, **👀 Eyes**, and **🤫 Hush** signals.

## How to Build the APK in Android Studio (Step-by-Step)

1. **Open the Project in Android Studio**:
   - Download or clone this repository to your computer.
   - Launch **Android Studio** (Hedgehog, Iguana, Jellyfish, Koala, or newer).
   - In Android Studio, click **Open** (or **File → Open...**).
   - **Important**: Select the **`android`** subfolder inside this project (not the root directory).
   - Android Studio will detect Gradle and automatically sync all project dependencies using Gradle 8.6.

2. **Connect Your Android Phone (or use an Emulator)**:
   - To install directly on your phone:
     - On your phone, go to **Settings → About phone** and tap **Build number** 7 times to enable Developer options.
     - Go to **Settings → System / Developer options** and turn on **USB debugging**.
     - Connect your phone with a USB cable (allow USB debugging prompt on your phone).
   - Your device will appear in the toolbar device selector in Android Studio.

3. **Generate the APK (or Install Directly)**:
   - **Direct Install**: Click the green **Run (▶)** button in Android Studio to build and install immediately on your connected phone.
   - **Generate APK file**: In the top menu bar, go to:
     **Build → Build Bundle(s) / APK(s) → Build APK(s)**
   - Once the build finishes, click the blue **"locate"** notification popup at the bottom right.
   - Your APK file is ready at:
     `app/build/outputs/apk/debug/app-debug.apk`
   - You can share this `.apk` file directly with your partner via Google Drive, WhatsApp, Telegram, or email.

## Setting Up the Widget on Your Phone
1. Open the **Red Threads** app on your phone once.
2. Enter your Pair Code (e.g. `SYNC-777`).
3. Select whether you are **Person 1** or **Person 2**.
4. Tap **"Save & Pin Widget to Home Screen"** (or long-press any empty space on your Android home screen → **Widgets** → **Red Threads**).
5. Tap **❤️ Heart**, **👀 Eyes**, or **🤫 Hush** directly from your home screen to send signals in real time!
